# ADR-005 — LLM-as-a-Judge Evaluation Framework

**Status:** Accepted
**Date:** Phase 5

## Context
No quantifiable measure of retrieval/answer quality existed; regressions would go undetected.

## Decision
- `medibot/evaluation/` package: runner (CLI) + 5 evaluators + `LLMJudge` (Gemini→Groq) + programmatic retrieval metrics.
- 5 categories → curated JSON datasets (15 cases): retrieval, accuracy, memory, citation, safety.
- Every run persisted to `evaluation_runs` / `evaluation_case_results` (SQLite) + JSON report (gitignored); Streamlit dashboard reads history.
- Evaluation couples into the repo so it runs with `medibot evaluate`.

## Consequences
- Reproducible, traceable quality. Initial benchmark (2026-09-13 run 3): accuracy 9.7, safety 9.3, memory borderline, citation 0 — surfaced the unnumbered-context citation gap (see `07-learning/known-gaps.md`).
