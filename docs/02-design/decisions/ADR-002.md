# ADR-002 — Gemini Primary + Groq Automatic Fallback

**Status:** Accepted
**Date:** Phase 2

## Context
Prior app relied on a single Groq model. Provider outages would give no answers.

## Decision
- `FallbackChatModel` in `services/llm.py`: try providers in order on every call; on exception log + try next.
- Gemini primary (`gemini-3.6-flash`), Groq fallback (`openai/gpt-oss-20b`).
- Expose `provider` attribute for analytics; never include secrets.
- Gemini safety settings: keep BLOCK_ON harmful categories (medical tool, not a movie app).

## Consequences
- High availability; ~60s worst-case delay when Gemini fails (auth/429 retries) before Groq fallback.
- Deprecated models must be tracked: `llama-3.1-8b-instant` and `gemini-2.5-flash` both retired by providers in Sept 2026 → replaced with `openai/gpt-oss-20b` and `gemini-3.6-flash`.
