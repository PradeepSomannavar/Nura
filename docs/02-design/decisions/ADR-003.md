# ADR-003 — SQLite + SQLAlchemy for Persistence

**Status:** Accepted
**Date:** Phase 1

## Context
Memory (sessions, messages, summaries) and later eval history needed durable storage in a single-tenant local MVP.

## Decision
- SQLite via SQLAlchemy (`core/database.py`): `ChatSession`, `ChatMessage`, `ConversationSummary` (Phase 1); `EvaluationRun`, `EvaluationCaseResult` (Phase 5).
- `Base.metadata.create_all` on app startup.
- Scoped `SessionLocal` dependency; Pydantic DTOs in/out.

## Consequences
- Zero-config, file-backed, refresh-surviving state. Postgres/Redis deferred as ADRs if scale or multi-user arrives.
