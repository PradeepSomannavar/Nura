# ADR-004 — Hybrid Memory: Raw Buffer + Rolling Summary

**Status:** Accepted
**Date:** Phase 4

## Context
Long conversations blow the LLM prompt token budget; full history re-sent each turn is wasteful.

## Decision
- Keep last 5 turns (10 messages) as raw buffer in the prompt.
- Older evicted turns → LLM-compressed **rolling clinical summary** (conditions, symptoms, treatments, open follow-ups) persisted to SQLite.
- `HybridMemory(session_id, db, buffer_turns)` loads summary + buffer per session; evicts oldest 2 turns when over budget.

## Consequences
- Bounded token cost + long-term continuity. Verified live: 7-turn conversation → Gemini summary, buffer capped at 4, summary reloaded from DB.
- Frontend refresh-restore wiring is deferred to Phase 6 (service-level verified).
